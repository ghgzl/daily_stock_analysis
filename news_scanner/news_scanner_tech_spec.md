# A股新闻事件主动扫描 · 技术清单（news_scanner）

> 定位：作为 `daily_stock_analysis`（DSA）的 companion 模块 —— 盘前/盘中全市场事件扫描，
> 与 DSA 的"盘后自选股 LLM 分析"互补。本清单是其设计规格；配套雏形脚本 `news_scanner.py` 是其最小实现。

---

## 0. 设计原则

1. **新闻只负责"发现"，资金负责"确认"**：新闻信号一律先进观察池，量价验证后才进入可操作名单。
2. **先规则后模型**：MVP 用词典规则（零成本、可解释、可审计），LLM 增强作为 V2。
3. **与 DSA 松耦合**：独立目录、独立运行，通过文件/接口单向喂给 DSA，不侵入 DSA 主流程。
4. **合规边界**：只处理公开信息；不接触内幕、不传播未公开信息、不参与操纵。

## 2. 抓取频率设计

| 时段 | 动作 | 频率 |
|------|------|------|
| 盘前 07:30–09:15 | 隔夜外盘 + 政策/公告汇总 → 生成"今日事件简报" | 每 15min 刷新 |
| 盘中 09:30–11:30 / 13:00–15:00 | 快讯/公告实时扫描 → 新事件入池 → 验证层打标 | 每 5min |
| 午间 11:30–13:00 | 上午热点归因 + 观察池状态更新 | 1 次 |
| 盘后 15:00–15:30 | 全天事件归档、观察池收盘状态、信号统计 | 1 次 |
| 晚间 20:00 后 | 回测增量、词典/阈值迭代建议 | 1 次 |

**节流原则**：单日新闻量级大，策略是"高频抓、低频判"——抓取 5min 一次，但事件入库与打分只在"新内容出现"时触发；重复内容按标题相似度去重。

## 3. 事件词典设计

### 3.1 事件类型（E1–E6）

| 编码 | 事件类型 | 判别关键词（示例） | 默认强度权重 |
|------|----------|--------------------|--------------|
| E1 | 政策催化 | 国务院、发改委、工信部、央行、证监会、规划、试点、专项资金、补贴、减免、新规、实施意见 | 0.35 |
| E2 | 产业催化 | 涨价、提价、订单、中标、签约、技术突破、量产、新品发布、获批、扩产 | 0.25 |
| E3 | 并购重组 | 收购、并购、重组、借壳、重大资产重组、股权转让、要约 | 0.20 |
| E4 | 业绩事件 | 预增、扭亏、超预期、大幅增长、业绩预告 | 0.10 |
| E5 | 股东行为 | 增持、回购、举牌、减持、质押、解禁 | 0.05 |
| E6 | 监管风险 | 立案、处罚、问询函、警示函、ST、退市、调查 | -0.30（反向信号） |

### 3.2 行业/概念映射（事件 → 受益方向）

MVP 用静态映射表 + 东财概念板块名模糊匹配：

- "人工智能 / 算力 / 大模型 / 智算" → AI算力、光模块、CPO、液冷
- "半导体 / 芯片 / 晶圆 / 国产替代" → 半导体设备、材料、设计、封测
- "新能源汽车 / 固态电池 / 充电桩" → 电池、锂电材料、充电桩、整车
- "低空经济 / eVTOL / 无人机" → 低空经济、通感一体
- "机器人 / 人形机器人 / 灵巧手" → 机器人、减速器、传感器
- "商业航天 / 卫星 / 星链" → 商业航天、卫星互联网
- "数据要素 / 数字经济 / 数据交易" → 数据要素、国资云
- "创新药 / 医药集采 / 疫苗" → 创新药、CXO、医疗器械
- "电力设备 / 电网 / 特高压 / 储能" → 电网设备、储能、虚拟电厂
- "设备更新 / 以旧换新 / 家电下乡" → 机械设备、家电、汽车

映射方式：命中事件文本中的方向词 → 查静态表得概念名 → 用东财概念板块成分（`stock_board_concept_cons_em`）展开到个股。静态表不足时降级为"仅输出方向标签"，不强行映射到个股（避免错配）。

### 3.3 事件强度评分（0–100）

```
强度 = 60 × 类型权重(E1–E6) 
     + 15 × 来源权重(S1–S4 官方=1.0 / 快讯=0.8 / 媒体=0.5)
     + 15 × 政策级别(中央=1.0 / 部委=0.8 / 地方=0.5)   ← E1 时生效
     + 10 × 新颖度(当日首次出现=1.0 / 重复=0.3)
```
- ≥70：高优先级 → 盘中实时跟踪 + 验证
- 40–69：中优先级 → 入观察池（默认档）
- <40：低优先级 → 归档，不提示

## 4. 验证指标与阈值（第二道闸门）

新闻入池 ≠ 买入。观察池个股必须满足**资金验证**才进入"可操作名单"：

| 指标 | 数据来源 | 阈值（初值，待回测校准） |
|------|----------|--------------------------|
| 板块涨幅 | 东财行业/概念板块 | ≥ 3% |
| 板块量比 | 板块成交额/5日均量 | ≥ 2.0 |
| 板块涨停家数 | 板块成分统计 | ≥ 3 只 |
| 个股竞价高开 | 竞价撮合数据 | ≥ 2% |
| 个股量比 | 个股行情 | ≥ 2.5 |
| 封单强度（涨停时） | 盘口数据（可选） | 封单额 ≥ 5000 万 |

**决策规则**：高优先级事件 + 验证 5 项中 ≥3 项命中 → 进入当日可操作名单；否则留在观察池待次日确认。验证失败的新闻一律丢弃并计入误报日志。

## 5. 观察池输出结构

输出文件：`watchlist/<日期>.csv`（同时输出 `.json` 供程序消费）

| 字段 | 说明 |
|------|------|
| event_id | 事件哈希（去重用） |
| event_time | 事件入库时间 |
| event_type | E1–E6 |
| title | 事件标题/原文摘要 |
| source | S1–S8 |
| strength | 强度分 0–100 |
| direction | 受益方向（概念名，可多个） |
| stocks | 映射到个股代码（可空） |
| verify_status | 未验证 / 已确认 / 已否决 / 已过期 |
| verify_signals | 命中的验证指标列表 |
| action | 观察 / 可操作 / 放弃 |

## 6. 回测口径（信号有效性检验）

**研究问题**：按本系统筛选出的"高优先级事件 + 资金验证"名单，是否在 T+1~T+5 产生超额收益？

- **样本**：事件入池日 = T。持仓窗口：T+1 开盘买入，持有 1 / 3 / 5 个交易日，T+n 收盘卖出。
- **基准**：同期沪深300（或中证全指）收益，计算超额收益。
- **分组对比**：
  - A组：仅事件强度 ≥70（无验证）
  - B组：事件强度 ≥70 + 验证命中 ≥3（完整信号）
  - C组：随机新闻组（对照，检验是否存在幸存者偏差）
- **指标**：胜率（超额 >0 占比）、平均超额收益、累计超额、最大回撤、信号频率（月均触发次数）、换手成本敏感性（单边 0.1% 冲击成本）。
- **最低样本要求**：单组 ≥ 60 个信号；覆盖 ≥ 2 个不同政策周期（避免单一窗口过拟合）。
- **迭代闭环**：每次回测后输出"误报日志 Top 事件类型 + 失效阈值"，据此调整词典权重与阈值，调整后必须重跑全量历史。

**数据限制说明**：免费新闻接口一般只保留近 1–3 个月快讯，长期历史新闻需自建存档（脚本每次运行增量落库，SQLite），跑满 3 个月后再做正式回测。

## 7. 与 daily_stock_analysis 的集成设计

| 集成点 | 方式 | 说明 |
|--------|------|------|
| ① 观察池 → DSA 自选股 | news_scanner 输出的"可操作名单"按日追加/替换 DSA 的 watchlist 配置 | 让盘后 LLM 分析带上当日事件候选 |
| ② 事件简报 → DSA Prompt | 将当日 Top 事件摘要注入 DSA 的 LLM 分析 prompt | 盘后分析获得"今天为什么涨"的上下文 |
| ③ 通知层复用 | 复用 DSA 的通知通道（企业微信/飞书/Telegram）推送观察池 | 零成本接入已有推送基建 |
| ④ 回测模块复用 | DSA 已带 backtest 模块，可直接验证事件信号 | 避免重复造轮子 |
| ⑤ 数据层复用 | 两者共用 AkShare/Tushare 数据层，注意限流错峰 | 避免同一接口并发触发风控 |

**集成顺序建议**：先以独立脚本跑通 S1/S3/S6 → 产出观察池 → 手动检查 2 周 → 再接入 ①② ③ → 最后 ④ 回测闭环。

## 8. 合规清单（必须遵守）

1. 只抓取和处理**公开可获取**的信息；不获取、不使用内幕信息。
2. 不利用未公开信息交易；不传播可能误导他人的"小作文"。
3. 不参与、不组织拉抬打压、抢帽子等操纵市场行为。
4. 注意数据源使用条款（akshare 免费但请遵循各数据方规则；商业源按授权）。
5. 本系统输出仅作研究/信息整合用途，不构成投资建议。

## 9. 里程碑

| 阶段 | 内容 | 验收 |
|------|------|------|
| M0（本周） | 雏形脚本跑通：抓取→词典分类→观察池 CSV | 连续 3 个交易日有输出，可人工复核 |
| M1（2 周内） | 加验证层（板块/个股量价）+ 误报日志 + SQLite 存档 | 观察池可操作名单 ≤5 只/日，误报率可统计 |
